# NccHub デザインシステム仕様書

本書は NccHub のUIデザインシステム、デザイントークン、コンポーネント規約を定義する正本です。
すべてのトークン値には選定の根拠、アクセシビリティ基準、適用意図を定めています。

---

## 1. 設計思想と基本方針

NccHub は、校内ハッカソンの作品を学生が投稿・閲覧・評価するWebプラットフォームです。
過度な装飾を排し、制作物の魅力がもっとも引き立つ「シンプル＆スタイリッシュ」なUIを保ちながら、学校のアイデンティティを確立します。

1. **ブランドの統一感**: NCCロゴから抽出したオレンジと青の2色をPrimary / Secondaryの基軸として配します。
2. **アクセシビリティの保証**: すべての文字とUI要素について、WCAG 2.1 AA 基準（通常テキスト 4.5:1 以上、大見出し・UI境界 3:1 以上）のコントラスト比を満たします。
3. **明快な視覚リズム**: 4px / 8px をベースとする偶数グリッドと、同心円に基づく角丸階層により、破綻のない画面構成を維持します。
4. **ダークモードへの最適化**: 純黒ではなく、目に優しく視認性の高い階調（`#121212` / `#1C1C1E`）を用い、彩度と明度を個別にチューニングします。

## 4. タイポグラフィシステム

### 4.1 フォントスタック

- **UI / 本文**: `'LINE Seed JP', system-ui, -apple-system, 'Hiragino Kaku Gothic ProN', 'Hiragino Sans', Meiryo, sans-serif`
  - 幾何学的で現代的な造形を持ち、英数字・仮名・漢字のバランスが極めて優れる LINE Seed JP を主フォントとしています。
- **コード / 作品コード**: `ui-monospace, 'SF Mono', 'Roboto Mono', Menlo, Consolas, monospace`
  - 作品コード `XXXX-XXXX` の英数字誤認（0とO、1とI等）を防ぐため、等幅フォントを必須指定としています。

### 4.2 タイプスケール（Major Second / 8px 調和）

| トークン名 | フォントサイズ | 行高（line-height） | 用途・適用要素 |
|---|---|---|---|
| `--text-xs` | `0.75rem` (12px) | `1.4` | バッジ、画像拡大カウンタ、微小注記 |
| `--text-sm` | `0.875rem` (14px) | `1.5` | 投稿日時、タグ、入力ヒント、エラーテキスト |
| `--text-base` | `1rem` (16px) | `1.65` | 本文段落、標準ボタン、フォーム入力テキスト |
| `--text-lg` | `1.125rem` (18px) | `1.4` | サブヘッド、リンクボタン、強調注記 |
| `--text-xl` | `1.25rem` (20px) | `1.4` | H3、カード見出し |
| `--text-2xl` | `1.5rem` (24px) | `1.3` | H2、セクション見出し、作品コード（大） |
| `--text-3xl` | `1.875rem` (30px) | `1.25` | H1、画面メインタイトル |

### 4.3 フォントウェイト

- `--font-regular: 400`: 本文、説明文、プレースホルダ。
- `--font-bold: 700`: 見出し（H2/H3）、ボタンテキスト、フォームラベル、いいねカウント。
- `--font-heavy: 800`: ページタイトル（H1）、ブランドロゴ表記。

## 5. スペーシングシステム（4px / 8px Grid）

画面全体のリズムと余白の予測可能性を高めるため、すべての余白は 4 の倍数で構成します。

| トークン名 | サイズ | 主な用途 |
|---|---|---|
| `--space-1` | `4px` | アイコンとテキストの間隔、微細なインラインマージン |
| `--space-2` | `8px` | ボタン内部ギャップ、タグ間の隙間、チップ余白 |
| `--space-3` | `12px` | 入力欄上下パディング、ギャラリーのグリッド隙間 |
| `--space-4` | `16px` | カード内パディング、フォームフィールド間隔、ヘッダー余白 |
| `--space-5` | `20px` | フィールド下マージン、画面の左右基準パディング（モバイル） |
| `--space-6` | `24px` | セクション間マージン、カードグリッド隙間、見出し下余白 |
| `--space-8` | `32px` | 大セクション間隔、フォーム送信ボタン上部マージン |
| `--space-10` | `40px` | コントロールバー（検索・ソート）上部マージン |
| `--space-12` | `48px` | 空状態（ステータスメッセージ）の上下パディング |
| `--space-16` | `64px` | コンテナ下部（スクロール末尾）パディング |

## 6. 角丸・境界線・シャドウ・モーション

### 6.1 角丸（Border Radius）
要素同士の包含関係において違和感が生じないよう、サイズ比率を維持したスケールを採用しています。

- `--radius-xs: 4px`: フォーカスリング、極小インジケータ。
- `--radius-sm: 6px`: バッジ、タグチップ、サムネイル画像。
- `--radius-md: 10px`: **基本単位**。ボタン、テキスト入力、カード枠、モーダル。
- `--radius-lg: 14px`: 大型コンテナ、重要ダイアログ。
- `--radius-full: 9999px`: ピル型要素、丸型アバター。

### 6.2 境界線とフォーカスリング
- `--hairline: 0.5px solid var(--color-border)`: シャープで洗練された印象を与える超極細罫線。
- `--focus-ring: 0 0 0 2px var(--color-bg), 0 0 0 4px var(--color-primary)`: キーボード操作時に背景色との境界を確保しつつ視認できる2重リング（WCAG 2.4.7 準拠）。

### 6.3 エレベーション（Shadow）
装飾過多を排しつつ、前面に浮き上がる要素の階層を表現します。

- `--shadow-sm`: `0 1px 2px 0 rgba(0, 0, 0, 0.05)`（微小な浮き上がり）
- `--shadow-md`: `0 4px 6px -1px rgba(0, 0, 0, 0.08), 0 2px 4px -2px rgba(0, 0, 0, 0.05)`（カードホバー）
- `--shadow-lg`: `0 10px 15px -3px rgba(0, 0, 0, 0.10), 0 4px 6px -4px rgba(0, 0, 0, 0.05)`（合言葉ゲート、モーダル）

### 6.4 モーション（Transition）
- `--transition-fast: 150ms cubic-bezier(0.4, 0, 0.2, 1)`: ボタンホバー、背景色変化、フォーカス枠。
- `--transition-base: 200ms cubic-bezier(0.4, 0, 0.2, 1)`: プログレスバーの進捗アニメーション、展開。

## 7. コンポーネントスタイル規約

### 7.1 ボタン（Buttons）
1. **Primary Button (`.btn.btn-primary`)**:
   - 背景: `var(--color-primary)`（NCC Orange）
   - 文字色: `var(--color-primary-contrast)`
   - 用途: 「投稿する」「作品を保存」「合言葉で入る」など、画面内で唯一の主要アクション。
2. **Secondary Button (`.btn.btn-secondary`)**:
   - 背景: `var(--color-secondary-subtle)` / 枠線: `var(--color-secondary)` / 文字: `var(--color-secondary-text)`
   - ホバー時: 背景 `var(--color-secondary)` / 文字: `var(--color-secondary-contrast)`
   - 用途: 補助アクション、情報リンクボタン。
3. **Danger Button (`.btn.btn-danger`)**:
   - 背景: `var(--color-surface)` / 枠線: `var(--color-danger)` / 文字: `var(--color-danger)`
   - 用途: 「作品を削除」「キーを削除」などの破壊的操作。
4. **Ghost / Default Button (`.btn`)**:
   - 背景: `var(--color-surface)` / 枠線: `var(--hairline)` / 文字: `var(--color-text)`
   - 用途: 「一覧へ戻る」「プレビュー切替」「キャンセル」などの通常アクション。

### 7.2 バッジ（Badges）
1. **動画バッジ (`.badge.overlay-badge.video`)**:
   - 背景: `var(--color-secondary)`（NCC Blue） / 文字: `var(--color-secondary-contrast)`
   - 用途: 作品一覧カード上の「動画あり」サイン。
2. **変換中バッジ (`.badge.overlay-badge.processing`)**:
   - 背景: `var(--color-surface)` / 枠線・文字: `var(--color-warning)`
   - 用途: サーバー側動画トランスコード中の進行表示。
3. **いいねボタン (`.like-btn`)**:
   - 非アクティブ: 白地＋ヘアライン罫線。
   - アクティブ: 文字・枠線に `var(--color-like)`（NCC Orange）＋背景に `var(--color-primary-subtle)`。

### 7.3 フォーム・入力
- 入力欄はフォーカス時に `border-color: var(--color-primary)` となり、外側に `3px` の `var(--color-primary-subtle)` グローを表示。
- ドラッグ＆ドロップゾーン（`.dropzone`）は、ファイルドラッグ時に `var(--color-primary)` 枠と `var(--color-primary-subtle)` 背景へハイライト。
- 作品コード（`code.work-code`）は等幅フォント（`--font-mono`）を用い、`var(--color-primary-text)` で最も目立たせる。

## 8. 互換性と移行

既存のコード資産を壊さず安全に移行するため、旧CSS変数（`--accent`, `--border`, `--bg`, `--muted` 等）は新トークン体系へのエイリアスとして `web/src/app.css` の `:root` にて完全維持しています。
今後の新規実装では、セマンティックで意図の明確な新トークン（`--color-primary`, `--color-secondary` 等）を優先して使用します。
