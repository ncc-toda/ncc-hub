# 先生向け運用マニュアル

校内ハッカソンで NccHub を運用する教員向けの管理手順書です。

## 1. 管理画面へのログイン

1. ブラウザで管理画面 `https://ncchub.ncc-system.jp/_/` を開きます。
2. 管理者メールアドレスとパスワードを入力してログインします。
3. ログインに成功するとコレクション一覧が表示されます。

## 2. イベントの準備

作品の投稿を受け付ける前に、イベントを 1 件作成します。
設置時に `deploy/install.sh` へ `--event-slug` を渡していれば作成済みです。

1. 左メニューの `events` を選択します。
2. 「New record」をクリックします。
3. 以下の項目を入力します。
   - `name`: イベント名（例: 文化祭くじ引きアプリ開発）
   - `slug`: URL に使用する半角英数字（例: `fes2026`）
   - `passphrase`: 合言葉（8 文字以上、学生に周知する文字列）
   - `max_video_bytes`: 動画の最大サイズ（初期値 `2147483648` は 2 GB）
   - `submissions_open`: チェックを入れ有効（`true`）にします。
4. 「Save changes」をクリックして保存します。

## 3. 学生への周知

作成したイベントの URL と合言葉を学生に案内します。

- 案内 URL: `https://ncchub.ncc-system.jp/e/<slug>`
- 案内内容: イベント URL、合言葉、投稿締切日時
- あわせて次の 2 点を必ず伝えます。
  - 投稿内容に名前・学籍番号・クラスを書かないこと。
  - 投稿後に表示される「作品コード」を控えておくこと。後日アンケートで回収します。

学生はアカウント登録なしで投稿できます。
閲覧や投稿を行うには合言葉の入力が必要です。

## 4. 作者の確認

**本サイトは作者を特定する情報を一切保持しません。**
氏名・クラス・連絡先の入力欄はどこにもなく、管理画面にも記録がありません。
誰がどれを投稿したかは、本サイトの外で行うアンケートと「作品コード」で突き合わせます。

作品コードは投稿完了時に投稿者本人にだけ表示される `XXXX-XXXX` 形式の文字列です。

1. 別途アンケート（Google フォーム等）で、氏名と作品コードを回収します。
2. 管理画面の左メニューから `work_secrets` を選択します。
3. 検索バーで `work_code` に回答された作品コードを入力し、該当作品（`work`）を特定します。

アンケートの回答は本サイトとは別に保管してください。
両方を同じ場所に置くと、匿名性を守る意味がなくなります。

## 5. 編集キーの照会対応

作品の編集や削除には、投稿時に発行された編集キーが必要です。
学生が編集キーを紛失した場合は、教員が管理画面で確認して伝えます。

1. 管理画面の `work_secrets` から該当作品を探します。
2. 本人確認を行った上で、`edit_key` の値を学生に伝えます。

氏名の記録が無いため、本人確認は**その学生が作品コードを言えること**を根拠にします。
作品コードも紛失している場合は、投稿内容を本人に説明させて教員が判断します。

## 6. 投稿締切後の対応

ハッカソンの投稿締切時刻が過ぎたら、投稿受付を停止します。

1. 管理画面の `events` を開きます。
2. 該当イベントを選択します。
3. `submissions_open` のチェックを外し（`false`）、保存します。
4. 停止後は作品の作成・編集・削除・動画アップロード・いいねが停止します。
5. 既存作品の一覧および詳細の閲覧は引き続き可能です。

## 7. 不適切な投稿への対処

ガイドラインに反する投稿があった場合は、教員が管理画面から削除します。

1. 管理画面の `works` を開きます。
2. 該当する作品レコードを選択し、削除します。
3. 連鎖削除により、画像、動画、編集キー、作品コード、いいね情報も自動で完全に消去されます。

## 8. 注意事項

- **`events` レコードは絶対に削除しないでください。**
- イベントを削除すると、紐づくすべての作品や提出ファイルが連鎖削除されます。
- 過去のイベントを残したまま、新しいイベントを別 `slug` で追加運用できます。

## 9. バックアップ

毎日午前 3:00 に自動でバックアップが取得され、最新 7 世代が保持されます。
管理画面の Backups から手動取得とダウンロードもできます。
コマンドでの取得とサーバー側の手順は [deployment.md](./deployment.md) の §8 を参照してください。
